# rules/ — the rules system folder

Part of the AI Laws environment (repository root: https://github.com/Tonypost949/ailaws). The system itself is defined in RULES.md at the repository root.

| Path | What it is |
|---|---|
| `RULES_REGISTER.md` | Every rule in the system, with its status (PROPOSED / TESTING / PROVEN / stays-a-rule / became-a-tool / RETIRED / PROMOTED) |
| `RULE_TEST_LOG.md` | Dated records of rules applied on live work — the evidence a promotion verdict must cite |
| `candidates/` | Verbatim candidate texts under test, exactly as written by their author — currently `V2_AITECHVERSE_FULLTEXT.md`, the owner's AILAWS V2 draft, listed for testing on 2026-11-03. **Candidate texts are not laws.** |

Changes to anything in this folder follow the same discipline as the rest of the repository: GitHub-first, approved by the owner, archived, undoable, and logged in AILAW_ACTIVITY_LOG.md with strict timestamps.

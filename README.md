## 👗 Important Note on Android Storage & `/sdcard/`

> **Note for Android Users Without Physical SD Cards:**
> On Android, `/sdcard` **does NOT require a physical micro-SD card**. 
> 
> For legacy compatibility, the Android operating system maintains `/sdcard` as a universal system symlink (alias) that maps directly to the device's **built-in internal flash storage**:
> ```text
> /sdcard  --->  /storage/self/primary  --->  /storage/emulated/0
> ```
> Therefore, `/sdcard/ailaws.md` works seamlessly on **all** Android phones, tablets, and emulators regardless of whether a physical micro-SD slot or card exists.
>
> **Equivalent internal storage paths on Android:**
> - `/sdcard/ailaws.md` *(Default universal alias)*
> - `/storage/emulated/0/ailaws.md` *(Absolute primary storage path)*
> - `~/ailaws.md` *(Termux user root)*
